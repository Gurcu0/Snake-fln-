# 🎮 HTML Web Oyunları

Bu projede HTML, CSS ve JavaScript kullanarak geliştirdiğim mini web oyunları yer almaktadır.

## 🕹️ Mevcut Oyunlar
- 🐍 **Yılan Oyunu (Snake Game)**: Klasik yılan oyunu, yemleri toplayarak puan kazan!

## 🚀 Canlı Demo
Oyunları tarayıcıda oynamak için: [Oynamak İçin Tıkla](https://kullaniciadi.github.io/depo-adi/)

## 🛠️ Kullanılan Teknolojiler
- HTML5
- CSS3
- JavaScript (ES6+)
